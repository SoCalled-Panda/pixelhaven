### Swapping in your own tracks

1. Download any royalty-free/CC track you like (see resource list below).
2. Drop the file into `scripts/audio-src/` (gitignored — recordings stay out
   of version control; only the processed OGG loops are committed).
3. Add an entry to `SOURCES` in `scripts/prepare-audio.mjs` with the file
   name, trim window (seconds), title/description and license text.
4. Run `npm run prepare:audio` — it trims, builds a click-free loop seam,
   normalizes to −16 LUFS, encodes OGG q5 and rewrites `tracks.json`.
5. Commit the new OGG files + `tracks.json`.

## Fonts

- UI font: system font stack (`system-ui`/`Segoe UI`/Roboto/…). Nothing downloaded,
  nothing tracked.
- Pixel accent: monospace fallback is used for the few pixel-flavored labels; a
  bundled pixel webfont is deliberately avoided to keep the app offline-clean and
  license-simple. If you later add one (e.g. an OFL-licensed font), record it here.

## Runtime dependencies

React, React DOM, React Router (MIT). No analytics, ads, or trackers of any kind.

## Regenerating assets

```bash
npm run generate:artworks   # needs Node 18+
npm run prepare:audio       # needs ffmpeg on PATH; sources in scripts/audio-src/
npm run validate:assets     # verify integrity after any change
```
